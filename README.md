# Exercícios de Lógica de Programação e Estrutura de Dados em C

Este repositório foi criado para armazenar e organizar todos os exercícios práticos desenvolvidos durante as aulas da faculdade. O objetivo principal é consolidar a base teórica de algoritmos e acompanhar minha evolução na resolução de problemas com a linguagem C.

---

## Tecnologias e Conceitos Praticados
* **Linguagem:** C 
* **Estruturas de Dados:** Vetores e Matrizes 
* **Lógica:** Estruturas de repetição (`for`, `while`), condicionais (`if`, `else`, `switch-case`) e manipulação de índices de memória.

---

## Organização do Repositório

Até o momento, o projeto está estruturado da seguinte forma:

* **[📂 aula-5/](./aula-5):** Contém 10 exercícios práticos focados em **Vetores e Matrizes**.
  * Desafios de preenchimento, leitura, soma de elementos de matrizes e localização de índices específicos.
  * Resolução de problemas matemáticos utilizando arrays na memória.

---

## Como Executar os Códigos

Caso queira clonar este repositório e testar os arquivos locais, você precisará de um compilador C (como o GCC) instalado.

1. Clone o repositório:
   ```bash
   git clone https://github.com/davi93fernandes/logic.c.git
   ```
2. Acesse a pasta do exercício desejado:
   ```bash
   cd exercicios-logica-c/aula-5
   ```
3. Compile o arquivo (exemplo):
   ```bash
   gcc exercicio1.c -o exercicio1
   ```
4. Execute o programa:
   ```bash
   ./exercicio1
   ```
